An entry for the [Fortune Cookie Wisdom for Developers](https://make.fun/c/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) bounty on make.fun.

`main.ts` (Node 22, no network, deterministic) writes one original
fortune-cookie line for a software developer — 120 characters or fewer —
to `/output/entry.txt`.

## Run

```sh
node main.ts            # writes /output/entry.txt
node main.ts /tmp/out   # writes to a custom output directory
```
